# Chega Junto para Android

**AMBIENTE DEMONSTRATIVO — SISTEMA NÃO OFICIAL.** Aplicativo do projeto Chega Junto para demonstração com dados fictícios, sem integração oficial com SUS ou governo.

## Baixar e instalar

[Baixar APK Android 0.7.0](https://github.com/jeffsilva03/Chega-Junto-Android/releases/download/android-v0.7.0/chega-junto-0.7.0.apk)

1. Abra o link acima no navegador do Android e baixe o arquivo APK.
2. Abra o arquivo baixado. Se o Android solicitar, permita a instalação por esse navegador.
3. Instale e abra **Chega Junto**.
4. Entre com a mesma conta demonstrativa de paciente usada no aplicativo Web, ou cadastre uma conta fictícia.

O app precisa de internet e usa o mesmo ambiente demonstrativo público da versão Web. Não depende do notebook ou da mesma rede Wi-Fi. A conta de operador do Portal é separada da conta de paciente.

Versão 0.7.0, build 7001, APK universal para arm64-v8a, armeabi-v7a e x86_64. Android API 24 ou superior. Tamanho: 57.748.801 bytes (aproximadamente 55 MiB).

Build release assinado com chave de teste Android; destinado à demonstração por instalação direta. Não é distribuição pela Play Store. Sessão somente em memória: reiniciar o app pode exigir novo login.
